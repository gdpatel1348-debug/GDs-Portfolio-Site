# GD's Portfolio Site

A modern, interactive portfolio website showcasing 3D design work and web development projects.

## 🚀 Features

- **3D Model Viewer**: Interactive Three.js 3D models
- **Smooth Animations**: Framer Motion powered animations
- **Responsive Design**: Tailwind CSS for mobile-first design
- **Contact Form**: EmailJS integration
- **Projects Showcase**: Sticky card scroll effect

## 🛠️ Tech Stack

- React 18
- TypeScript
- Vite
- Three.js
- Framer Motion
- Tailwind CSS
- EmailJS

## 📦 Installation

```bash
npm install
```

## 🏃‍♂️ Development

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```
